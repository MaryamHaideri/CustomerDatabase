# Customer Register

A simple offline customer register developed in Java.

## Features

- Add new customers
- Search for customers
- Remove customers
- Unique customer ID
- Validate phone numbers and email addresses
- Display customer information

## Technologies

- Java
- Object-Oriented Programming
- Git/GitHub

## Project Structure

- `Customer.java` – Represents a customer
- `CustomerRegister.java` – Manages customers
- `CustomerMenu.java` – Handles the user menu
- `Main.java` – Starts the application

## How to Run

Run the `Main.java` file to start the application.
